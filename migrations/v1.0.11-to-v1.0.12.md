# Migration Guide: `android-v1.0.11` → `android-v1.0.12`

---

## Breaking Changes (required)

### `AstroConnect(...)` composable removed

The standalone `AstroConnect(...)` composable has been removed. Use `AstroConnectView(...)` to display the SDK. The `AstroConnect` symbol still exists as the entry point for the static API (`preWarm`, `preload`, `clear`).

```kotlin
// BEFORE (v1.0.11)
import com.astropay.connect.AstroConnect

AstroConnect(
    configuration = configuration,
    onResult = { result -> /* ... */ }
)

// NOW (v1.0.12)
import com.astropay.connect.views.AstroConnectView

AstroConnectView(
    configuration = configuration,
    onResult = { result -> /* ... */ }
)
```

The parameter list and behavior are identical — only the symbol and import change.

---

## New Features (optional)

### Pre-warming *(since v1.0.12)*

Initialize the SDK in the background as early as possible (e.g. `Application.onCreate`) to reduce first-open latency. If `appIssuer` is provided, the co-branded header logo is also prepared in advance.

```kotlin
AstroConnect.preWarm(
    environment = "sandbox",
    appIssuer = "your-app-issuer"
)
```

### Pre-loading *(since v1.0.12)*

Pre-load the SDK with a specific configuration before presenting it. When `AstroConnectView` is later composed with the same configuration, it appears instantly with no loading screen.

```kotlin
AstroConnect.preload(configuration = configuration)
```

A pre-load is **single-use** and **configuration-bound** — see the README for details.

### Clear SDK data *(since v1.0.12)*

Reset cookies, local storage, and caches used by the SDK. Also discards any active pre-load.

```kotlin
AstroConnect.clear(environment = "sandbox")
```
