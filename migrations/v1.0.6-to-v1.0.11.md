# Migration Guide: `android-v1.0.6` → `android-v1.0.11`

---

## Breaking Changes (required)

### `AstroConfiguration` requires 2 new parameters

Since **v1.0.7**, the constructor requires `clientId` and `partnerUserId`. Projects that do not provide them will fail to compile:

```kotlin
// BEFORE (v1.0.6)
AstroConfiguration(
    environment = "production",
    appIssuer = "your-app-issuer",
    accessToken = "..."
)

// NOW
AstroConfiguration(
    environment = "production",
    appIssuer = "your-app-issuer",
    accessToken = "...",
    clientId = "your-client-id",        // REQUIRED
    partnerUserId = "user-123"           // REQUIRED
)

// Or using Builder pattern
AstroConfiguration.builder()
    .setEnvironment("production")
    .setAppIssuer("your-app-issuer")
    .setAccessToken("...")
    .setClientId("your-client-id")      // REQUIRED
    .setPartnerUserId("user-123")        // REQUIRED
    .build()
```

## Deprecations (non-breaking, but should be removed)

Since **v1.0.11**:

| Deprecated | Replace with |
|---|---|
| `showCloseButton` | `showHeader` |
| `autoSize` | `showHeader` |

Still functional but will produce compiler warnings.

## New Optional Parameters

### Phone data *(since v1.0.7)*

```kotlin
.setPhoneCode("54")         // optional
.setPhoneNumber("11...")    // optional
```

### Biometric grace period *(since v1.0.10, only if using biometrics)*

```kotlin
.setBiometricGracePeriod(120)   // seconds (0–600), default 120
```

### Custom styling *(since v1.0.11)*

```kotlin
.setStyle(AstroStyle(
    backgroundColor = "#F5F5F5",
    header = AstroHeaderStyle(
        backgroundColor = "#FFFFFF",
        borderColor = "#E0E0E0",
        borderWidth = 1f,
        paddingHorizontal = 8f,
        paddingVertical = 8f
    )
))
```

> **Note:** When `style` is not provided, the SDK uses default colors based on the selected theme (light/dark/system).
>
> **Important:** When you override a color via `AstroStyle`, the SDK **stops using the theme-based default** for that property. This means you are responsible for providing the appropriate value for both light and dark modes. For example:
>
> ```kotlin
> val isDark = (context.resources.configuration.uiMode
>     and android.content.res.Configuration.UI_MODE_NIGHT_MASK) ==
>     android.content.res.Configuration.UI_MODE_NIGHT_YES
>
> val style = AstroStyle(
>     backgroundColor = if (isDark) "#041311" else "#FFFFFF",
>     header = AstroHeaderStyle(
>         backgroundColor = if (isDark) "#061E1D" else "#EFEFEF"
>     )
> )
> ```

### Issuer logo in header *(since v1.0.11)*

```kotlin
.setShowHeaderLogo(true)   // displays issuer logo
```

## Changelog Summary

| Version | Changes |
|---|---|
| **v1.0.7** | Added required `clientId` and `partnerUserId` params. Added optional `phoneCode` and `phoneNumber`. |
| **v1.0.10** | Added `biometricGracePeriod` param. |
| **v1.0.11** | Added `AstroStyle` / `AstroHeaderStyle` for custom styling. Added `showHeader` and `showHeaderLogo` params. Deprecated `showCloseButton` and `autoSize`. Added issuer logo in header. |
